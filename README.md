# Журнал тренувань

Веб-програма для обліку тренувань: вправи, підходи, історія, статистика, вага тіла.
Працює без інтернету після першого відкриття. Усі дані зберігаються лише на пристрої
(резервна копія — через «Ще → Експорт»).

## Встановлення на iPhone

1. Відкрий посилання на програму в **Safari**.
2. Натисни «Поділитися» → «На початковий екран».

## Для розробки

- Запуск локально: `python -m http.server 5173`, потім http://localhost:5173
- Після зміни будь-яких файлів програми збільш `VERSION` у `sw.js`,
  інакше встановлена програма не побачить оновлення.
